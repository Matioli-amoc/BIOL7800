# Reproducible Albumin Protein Sequence Alignment

## Overview

This project performs a reproducible multiple sequence alignment of albumin protein sequences from six mammalian species.

The goal is to evaluate the conservation of albumin protein sequences across the selected species using publicly available protein sequences from UniProt.

The species included are:

* *Bos taurus* (cattle)
* *Ovis aries* (sheep)
* *Sus scrofa* (pig)
* *Equus caballus* (horse)
* *Homo sapiens* (human)
* *Mus musculus* (mouse)

## Research Question

How conserved are albumin protein sequences among six mammalian species?

## Data

Reviewed albumin protein sequences were obtained from UniProt using the following accession numbers:

* *Bos taurus*: P02769
* *Ovis aries*: P14639
* *Sus scrofa*: P08835
* *Equus caballus*: P35747
* *Homo sapiens*: P02768
* *Mus musculus*: P07724

The input data are not included in this repository. The `run_analysis.sh` script downloads the sequences directly from UniProt.

## Software

The analysis uses:

* MAFFT 7.526
* EMBOSS 6.6.0
* curl

The computational environment is specified in `environment.yml`.

## Installation

Create the Conda environment:

```bash
conda env create -f environment.yml
```

Activate the environment:

```bash
conda activate week5-mafft
```

## Running the Analysis

Run the complete analysis with:

```bash
./run_analysis.sh
```

The script will:

1. Download the six albumin protein sequences from UniProt.
2. Combine the sequences into a single FASTA file.
3. Perform a multiple sequence alignment using MAFFT.
4. Generate alignment statistics using EMBOSS `infoalign`.
5. Calculate SHA256 checksums for the input data and output files.

## Outputs

The analysis generates:

```text
output/
├── albumin_alignment.fasta
└── alignment_stats.txt
```

`albumin_alignment.fasta` contains the multiple sequence alignment generated by MAFFT.

`alignment_stats.txt` contains summary statistics for each protein sequence in the alignment generated using EMBOSS `infoalign`.

## Methods

Albumin protein sequences from six mammalian species were downloaded from UniProt in FASTA format. The sequences were combined into a single FASTA file and aligned using MAFFT v7.526 with the automatic alignment strategy and one computational thread.

Alignment statistics were generated from the resulting multiple sequence alignment using `infoalign` from EMBOSS v6.6.0.

SHA256 checksums were calculated for the downloaded data, combined input file, and analysis outputs to allow verification of file integrity and reproducibility.

## Reproducibility

After running the analysis, file integrity can be checked with:

```bash
sha256sum -c CHECKSUMS.txt
```

A successful reproduction should report `OK` for each file listed in `CHECKSUMS.txt`.
