# Replication submission files

The repository-root `CHECKSUMS.txt` belongs to the classmate and is the immutable canonical reference.

The `CHECKSUMS.txt` in this submission directory is Amanda's independently generated run manifest, copied from `../CHECKSUMS.generated.txt`. Its input/ and outputs/ paths are relative to the repository root, not this submission directory. Validate it from the repository root with `sha256sum -c submission/CHECKSUMS.txt`.

The replication report, verification log, scientific comparison, and agent execution record are supplied alongside it. Full raw terminal logs, failure diagnostics, exact environment specifications and path-only patches remain in ../evidence/. Per-stage logs remain in ../logs/.

The agent execution record is a factual work log, not a verbatim chat transcript. The application's conversation export may be submitted additionally if required by the course.
